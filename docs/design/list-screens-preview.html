Dove usarle

La stessa shell di lista, tre densità. La scelta non è per schermata: è per pubblico.

IndiceCantieri, Ticket, Rapportini: la lista operativa predefinita, con gruppi Oggi / Questa settimana / Altro.
SchedeSolo “il lavoro di oggi” o una lista con una prossima azione chiara per riga. Non per l’archivio.
RegistroClienti, Sedi, Commesse, Contratti, Prodotti, Materiali, Magazzini, Squadre, Pianificazioni, Report: l’ufficio confronta, non corre.

Raccomandazione

Adottare Indice come lista predefinita per tutti, con Registro come densità amministrativa per i master data. Tenere Schede per la corsia “oggi” di Cantieri/Ticket, non come lista principale.

La shell di lista condivisa: header + ricerca + filtri + gruppi + righe. Le varianti cambiano solo la riga, non la struttura.
